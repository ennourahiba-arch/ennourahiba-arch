# 11. Key Equations

## Measurements and Vectors

$$A_x = A\cos\theta, \qquad A_y = A\sin\theta$$
$$|\vec{A}| = \sqrt{A_x^2 + A_y^2}$$

## 1D Kinematics

$$v = v_0 + at$$
$$x = x_0 + v_0 t + \frac12 at^2$$
$$v^2 = v_0^2 + 2a(x-x_0)$$
$$x = x_0 + \frac{v+v_0}{2}t$$

## Free Fall

$$v = v_0 - gt$$
$$y = y_0 + v_0 t - \frac12 gt^2$$
$$v^2 = v_0^2 - 2g(y-y_0)$$

## Projectile Motion

$$v_{0x} = v_0\cos\theta, \qquad v_{0y} = v_0\sin\theta$$
$$T = \frac{2v_0\sin\theta}{g}$$
$$R = \frac{v_0^2\sin 2\theta}{g}$$
$$h_{\max} = \frac{v_0^2\sin^2\theta}{2g}$$

## Circular Motion

$$v = \omega r$$
$$a_c = \frac{v^2}{r} = \omega^2 r$$
$$T = \frac{2\pi}{\omega}, \qquad f = \frac1T$$

## Newton's Laws and Forces

$$\sum \vec{F} = m\vec{a}$$
$$f_s \le \mu_s N, \qquad f_k = \mu_k N$$
$$mg_{\parallel} = mg\sin\theta, \qquad mg_{\perp} = mg\cos\theta$$

## Work, Energy, Power

$$W = Fd\cos\theta$$
$$W_{net} = \Delta K$$
$$K = \frac12 mv^2$$
$$U_g = mgh$$
$$U_s = \frac12 kx^2$$
$$K_i + U_i + W_{nc} = K_f + U_f$$
$$P = \frac{W}{t} = Fv\cos\theta$$

## Momentum

$$p = mv$$
$$J = F\Delta t = \Delta p$$
$$\sum p_{before} = \sum p_{after}$$
$$x_{cm} = \frac{\sum m_ix_i}{\sum m_i}$$

## Waves

$$v = f\lambda$$
$$T = \frac1f$$
$$k = \frac{2\pi}{\lambda}, \qquad \omega = 2\pi f$$
$$y(x,t) = A\sin(kx-\omega t+\phi)$$
$$L = \frac{n\lambda}{2}, \qquad f_n = \frac{nv}{2L}$$
$$f' = f\frac{v \pm v_o}{v \mp v_s}$$

## Springs

$$F_s = -kx$$
$$\omega = \sqrt{\frac{k}{m}}$$
$$T = 2\pi\sqrt{\frac{m}{k}}$$
$$v_{max} = \omega A$$
$$a = -\omega^2 x$$
$$\frac{1}{k_{eq}} = \frac{1}{k_1} + \frac{1}{k_2} \quad \text{(series)}$$
$$k_{eq} = k_1 + k_2 \quad \text{(parallel)}$$

## Pendulums

$$\tau = -mgL\sin\theta$$
$$\theta'' + \frac{g}{L}\theta = 0 \quad \text{(small angle)}$$
$$\omega = \sqrt{\frac{g}{L}}$$
$$T = 2\pi\sqrt{\frac{L}{g}}$$
$$T = 2\pi\sqrt{\frac{I}{mgd}} \quad \text{(physical pendulum)}$$

## Quick Reference by Question Type

| If asked for... | Go to equation set |
|---|---|
| displacement/time with constant $a$ | 1D kinematics |
| maximum height/range | projectile motion |
| force balance | Newton's laws |
| speed from height or compression | energy |
| collision outcome | momentum |
| period of oscillation | springs or pendulums |
| frequency shift | Doppler effect |

## Fast Usage Tips

| Situation | First equation to try | Reason |
|---|---|---|
| Time is missing in a constant-acceleration problem | $v^2 = v_0^2 + 2a\Delta x$ | eliminates time immediately |
| Need speed from height or compression | energy conservation | directly relates states |
| Collision followed by sticking | momentum conservation | kinetic energy is not conserved |
| Spring network appears | equivalent $k$ first | simplify before SHM formulas |
| Pendulum period question | $T=2\pi\sqrt{L/g}$ | fastest route for small-angle motion |

## Mini Examples

### Example 1 — Speed from Height
An object falls from height $5\,\text{m}$ from rest, using $g=10\,\text{m/s}^2$.

$$v^2 = 0 + 2(10)(5) = 100$$
$$v = 10\,\text{m/s}$$

### Example 2 — Spring Period
A mass $m=1\,\text{kg}$ is attached to a spring with $k=100\,\text{N/m}$.

$$T = 2\pi\sqrt{\frac{1}{100}} = 0.2\pi \approx 0.63\,\text{s}$$
