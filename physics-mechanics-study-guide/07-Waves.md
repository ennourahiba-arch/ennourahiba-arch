## Wave Basics

A wave transfers energy without transporting matter overall.

| Quantity | Symbol | Relation |
|---|---|---|
| Wavelength | $\lambda$ | distance per cycle |
| Frequency | $f$ | cycles per second |
| Period | $T$ | $T=1/f$ |
| Wave speed | $v$ | $v=f\lambda$ |
| Amplitude | $A$ | maximum displacement |

---

## Traveling Waves

A common form is:

$$y(x,t) = A\sin(kx - \omega t + \phi)$$

with

$$k = \frac{2\pi}{\lambda}, \qquad \omega = 2\pi f$$

### Interpretation
- $A$: amplitude
- $k$: wave number
- $\omega$: angular frequency
- $(kx-\omega t)$: motion in the $+x$ direction

---

## Standing Waves

Standing waves form when two identical waves travel in opposite directions.

### String Fixed at Both Ends

$$L = \frac{n\lambda}{2}, \qquad f_n = \frac{nv}{2L}$$

### Key Terms
- node: zero displacement
- antinode: maximum displacement

---

## Wave Speed in Media

### On a String

$$v = \sqrt{\frac{T}{\mu}}$$

### Sound
Depends on the medium and temperature. In air near room temperature, use about $343\,\text{m/s}$ unless told otherwise.

---

## Doppler Effect

Observed frequency changes when source or observer moves.

$$f' = f\frac{v \pm v_o}{v \mp v_s}$$

Use:
- plus in numerator if observer moves toward source
- minus in denominator if source moves toward observer

## Worked Examples

### Example 1 — Wave Speed
A wave has $f=5\,\text{Hz}$ and $\lambda=2\,\text{m}$.

$$v = f\lambda = 10\,\text{m/s}$$

### Example 2 — Reading a Wave Equation
For $y = 0.5\sin(2\pi x - 4\pi t)$:

$$A = 0.5\,\text{m}$$
$$k = 2\pi \Rightarrow \lambda = 1\,\text{m}$$
$$\omega = 4\pi \Rightarrow f = 2\,\text{Hz}$$
$$v = f\lambda = 2\,\text{m/s}$$

### Example 3 — String Fundamental Frequency
A string of length $0.60\,\text{m}$ carries waves at $400\,\text{m/s}$.

$$f_1 = \frac{v}{2L} = \frac{400}{1.2} \approx 333\,\text{Hz}$$

### Example 4 — Doppler Effect, Source Approaching
An ambulance emits $800\,\text{Hz}$ while moving toward a stationary observer at $20\,\text{m/s}$. Let $v=340\,\text{m/s}$.

$$f' = 800\left(\frac{340}{340-20}\right) = 850\,\text{Hz}$$

### Example 5 — String Speed from Tension
A string has tension $10\,\text{N}$ and linear density $0.01\,\text{kg/m}$.

$$v = \sqrt{\frac{10}{0.01}} = \sqrt{1000} \approx 31.6\,\text{m/s}$$

---

## Quick Tips
- Frequency stays the same across boundaries; wavelength changes when speed changes.
- Higher amplitude means more wave energy.
- Standing waves require resonance conditions.
